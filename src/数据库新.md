### 本地/单机库（SQLite）

#### game
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| name | TEXT | 游戏名 |
| data | JSON | `{ editorNodeList, editorInfo, prefabList }` |
| version | TEXT | 语义化版本 |
| front_cover_id | INTEGER FK resource(id) | 封面资源 |
| description | TEXT | 描述 |
| created_at | INTEGER | 时间戳 |
| updated_at | INTEGER | 时间戳 |

#### work
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK |
| name | TEXT |
| data | JSON | `{ editorNodeList, editorInfo, prefabList }`（编辑器作品草稿，游戏本体由 editorNodeList 推导） |
| status | TEXT | draft/published |
| created_at | INTEGER |
| updated_at | INTEGER |

### resource（本地 / 线上通用）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER/BIGINT PK | 资源 ID |
| owner_id | INTEGER/BIGINT FK user(id) | 资源归属作者（本地可为空） |
| name | TEXT/VARCHAR | 展示名称 |
| type | TEXT/VARCHAR | image / audio / video / custom 等 |
| mime_type | TEXT/VARCHAR | `image/png`、`audio/ogg` |
| hash | TEXT/VARCHAR | 内容哈希（去重、防篡改） |
| size | INTEGER | 字节数 |
| storage | TEXT/VARCHAR | local / oss / cdn，表示储存方式 |
| relative_path | TEXT | 本地相对路径（如 `resources/image/xxx.png`） |
| url | TEXT | 访问地址（`file://...` 或 `https://...`） |
| visibility | TEXT/VARCHAR | private / unlisted / public |
| tags | JSON | 关键字 |
| status | TEXT/VARCHAR | active / deleted / blocked |
| created_at | INTEGER/DATETIME | |
| updated_at | INTEGER/DATETIME | |
#### save
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK |
| game_id | INTEGER FK game(id) |
| name | TEXT |
| data | JSON | `{ sceneId, extraData }`（sceneId 起始场景，extraData 运行时玩家状态） |
| created_at | INTEGER |
| updated_at | INTEGER |

### 线上库（MySQL/Postgres）

#### user（Steam 映射）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGINT PK | 平台内部主键 |
| steam_id | VARCHAR | Steam64 ID，唯一 |
| display_name | VARCHAR | 从 Steam 同步的昵称 |
| avatar_url | TEXT | Steam 头像 URL |
| profile_data | JSON | Steam API 的附加信息缓存 |
| payout_info | JSON | 结算/收款信息（作者必填） |
| role | ENUM('player','author','admin') | 权限控制 |
| created_at | DATETIME |
| updated_at | DATETIME |

> 只做 Steam OAuth 登录：`steam_id` 是唯一凭证，其余信息可定期同步；所有作品、资源、收益表都通过 `user.id` 做外键引用。

### 盈利 / 结算相关

#### wallet
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGINT PK |
| user_id | BIGINT FK user(id) |
| balance | DECIMAL(18,2) |
| currency | VARCHAR | 默认 CNY |
| created_at | DATETIME |
| updated_at | DATETIME |

#### transaction
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGINT PK |
| wallet_id | BIGINT FK wallet(id) |
| type | ENUM('deposit','purchase','refund','commission','payout') |
| amount | DECIMAL(18,2) | 正负数区分收入/支出 |
| reference_type | VARCHAR | game_purchase / payout / steam_revenue 等 |
| reference_id | BIGINT | 对应记录 |
| metadata | JSON |
| created_at | DATETIME |

#### game_pricing
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGINT PK |
| game_id | BIGINT FK game(id) |
| price | DECIMAL(18,2) | 作者设置的金币价格 |
| currency | VARCHAR | 默认 CNY |
| revenue_share | DECIMAL(5,2) | 作者分成比例，如 0.7 |
| effective_from | DATETIME |
| effective_to | DATETIME |
